# Amazon S3 (et compatibles)

Le type **S3** couvre tous les services compatibles avec l'API S3 : AWS S3, MinIO, Ceph, Scaleway Object Storage, Backblaze B2 (en mode S3), Wasabi, DigitalOcean Spaces, etc.

## Côté provider

### Amazon Web Services

1. Console AWS → **IAM** → **Users** → **Create user**
2. Onglet **Permissions** → attache une policy avec accès au bucket :

```json
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["s3:*"],
    "Resource": [
      "arn:aws:s3:::mon-bucket",
      "arn:aws:s3:::mon-bucket/*"
    ]
  }]
}
```

3. Onglet **Security credentials** → **Create access key** → choisir **Application running outside AWS**
4. Note `Access Key ID` et `Secret access key`

### MinIO

1. Connecte-toi à la console MinIO
2. **Identity** → **Users** → créer un user, lui donner accès aux buckets
3. **Service Accounts** → générer un Access Key et Secret Key pour ce user

### Scaleway Object Storage

1. Console Scaleway → **Object Storage** → créer un bucket
2. **IAM** → générer une **Clé API** avec accès à Object Storage
3. Note `Access key` et `Secret key`

### Ceph / autres

Demande à ton administrateur. Le principe est identique : Access Key + Secret Key + Endpoint.

## Côté rclone-ui

| Champ | Description |
|---|---|
| **Fournisseur** | Sélectionne dans la liste : AWS, Minio, Ceph, ou Autre |
| **Endpoint** | URL custom (requis pour Minio/Ceph, vide pour AWS). Ex. `https://s3.fr-par.scw.cloud` |
| **Région** | Ex. `eu-west-1` (AWS), `fr-par` (Scaleway), `us-east-1` (défaut Minio) |
| **Access Key ID** | La key publique |
| **Secret Access Key** | La key privée (champ password) |
| **ACL** | Optionnel : `private`, `public-read`, `bucket-owner-full-control`, etc. |

### Exemple Scaleway Object Storage

| Champ | Valeur |
|---|---|
| Fournisseur | Autre |
| Endpoint | `https://s3.fr-par.scw.cloud` |
| Région | `fr-par` |
| Access Key ID | `SCWXXXXXXXXXXX` |
| Secret Access Key | `00000000-0000-0000-0000-000000000000` |

### Exemple MinIO local

| Champ | Valeur |
|---|---|
| Fournisseur | Minio |
| Endpoint | `http://minio:9000` |
| Région | `us-east-1` |
| Access Key ID | `minioadmin` |
| Secret Access Key | `minioadmin` |

## Chemin source/destination

Dans la tâche, le chemin commence par le **nom du bucket**, suivi optionnellement d'un préfixe :

```
mon-bucket
mon-bucket/sous-dossier
mon-bucket/2026/01
```

## Astuces

- **--checksum** dans les options rclone supplémentaires accélère les sync incrémentales sur S3
- **--s3-storage-class STANDARD_IA** pour basculer en classe Infrequent Access
- **--s3-no-check-bucket** évite un appel HEAD si tu sais que le bucket existe (utile sur Wasabi)

Voir la [documentation rclone S3](https://rclone.org/s3/) pour la liste complète.
